# Short-Term Notes

Notes that only matter for a few days or weeks. Once something is done or stale, either delete it or move it to `Archive/`. If it turns out to matter long-term, move it to a permanent section.

| Note | What goes there |
| --- | --- |
| [Groceries](Groceries.md) | Shopping list, grouped by store section |
| [Reminders](Reminders.md) | Things to do by a certain date |
| [To-Do](To-Do.md) | Small tasks with no deadline |
| [Inbox](Inbox.md) | Quick captures to sort out later |
| [Archive](Archive/) | Finished or old lists, kept for reference |

## Habits

- Use `- [ ]` checkboxes and tick items off with `- [x]`.
- Clear out checked items about once a week.
- Empty the Inbox regularly by moving each item where it belongs.
